# Online Examination System

## 📌 Project Overview

The **Online Examination System** is a web-based application designed to conduct and manage examinations digitally. The system helps administrators manage exams and questions while providing users with an easy way to participate in online examinations.

This project aims to simplify the traditional examination process by providing a fast, secure, and user-friendly online platform.

---

## 🚀 Features

* 👨‍💼 Admin Management
* 👨‍🎓 User/Student Management
* 📝 Create and Manage Examinations
* ❓ Add and Manage Questions
* ✅ Online Exam Participation
* 📊 View Examination Results
* 🔐 Secure Login System
* 🗄️ Database Integration
* 💻 User-Friendly Interface

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/idb69/online-examination-system.git
```

### 2. Open the Project

Open the project in your preferred IDE, such as:

* IntelliJ IDEA
* Eclipse
* Spring Tool Suite (STS)

### 3. Configure the Database

Configure your database settings in the application configuration file.

### 4. Run the Application

Using Maven:

```bash
./mvnw spring-boot:run
```

Or on Windows:

```bash
mvnw.cmd spring-boot:run
```

### 5. Open in Browser

After the application starts successfully, open the application in your web browser using the configured localhost URL.
